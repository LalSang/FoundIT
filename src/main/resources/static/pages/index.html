Appalachian State University

Campus Lost & Found Portal

Items turned in across campus can be posted here. Browse the listing, find what's yours, and submit a claim.

How It Works

1

Lose Something?

Check the portal to see if someone has turned it in. Use filters to narrow down the search.

2

Find Something?

Report the item with a description and photo. Drop it off at a designated campus location.

3

Claim It

Verify ownership, then pick up your lost item from the designated return center.
